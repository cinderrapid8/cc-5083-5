# 单图自相似超分辨率工具（selfsimilar-sr）

从**单幅输入图像自身的多尺度结构**寻找可迁移的细节，在显式代价与置信度约束下
重建更高分辨率结果。零第三方运行时依赖，仅使用 Node.js 内置模块（含 `zlib`），
工程可离线、确定性复现。

## 界面怎样启动（不是只有脚本）

```bash
cd selfsimilar-sr
node cli/server.js          # 默认端口 8123，可加参数： node cli/server.js 9000
# 浏览器打开 http://localhost:8123/
```

启动后是“图像恢复窗口”，由自相似放大内核（`engine/`）直接驱动所有控件：

1. 选择输入 PNG → 内核解码并显示尺寸；
2. 选择放大倍率（2×/3×/4×）并调整参数（块大小、步长、金字塔层数、置信阈值、
   亮度代价、旋转代价、尺度代价、反投影迭代、降质 σ）；
3. 点击“运行自相似放大”，结果区在同一窗口显示 **SR 重建 / 双三次基线 / 迁移区域
   遮罩 / 置信热图 / 投回输入尺度图 / 观测残差图**，并给出残差 RMS、平均置信度、
   细节迁移占比；
4. 在 SR 图上点击任意目标块网格，可查看该块的局部候选、每个候选的尺度/旋转/亮度
   代价分解，以及是否因低于阈值而回退；
5. “参数影响扫描”对同一输入重跑多个置信阈值，对比迁移占比、置信度与残差。

**失败反馈回自相似放大**：内核抛出的任何错误（未上传、参数越界、块位置不存在等）
都通过 HTTP 接口返回并显示在界面状态栏，浏览器端不包含任何自行处理图像的逻辑。

## 命令行与批处理

```bash
# 单次重建：输出 SR/基线/投回图/残差/置信图/迁移遮罩/匹配索引/运行清单
node cli/run_sr.js tests/inputs/panes_LR.png runs/demo --scale 2 \
  --set confidenceThreshold=0.6 --set patchStride=4

# 参数扫描（六个参数各取若干值，输出汇总 JSON）
node cli/sweep.js tests/inputs/unique_LR.png runs/sweep_unique 2

# 一键复现：重新生成测试图 → 四场景评价 → CLI 清单
node tests/reproduce.js 2
```

## 算法与关键约束（`engine/`）

- `image.js`：图像容器、YCbCr 变换、Catmull-Rom 双三次重采样、高斯模糊、
  **已知降质模型** `degrade = 高斯模糊(σ) → 双三次降采样`。
- `match.js`：自相似匹配。候选只来自输入图及其按同一降质模型生成的下采样金字塔；
  积分图做粗筛、短列表精排；目标块排除自身邻域，防止“自匹配”虚高置信度。
  每个候选都带显式代价：
  - `ssdPerPx`：去均值后的外观误差（对亮度偏移不敏感的结构误差）；
  - `brightnessDelta` 与亮度代价权重；
  - `rotationPenalty`：0/90/180/270° 旋转的显式惩罚，零旋转代价最低；
  - `scalePenalty`：候选所在金字塔层级越深（越模糊）代价越高；
  - `cost = ssdPerPx + w·|Δ亮度| + 旋转惩罚 + 尺度惩罚`。
- `sr.js`：置信度由“最优/次优代价间隔 + 拟合质量 + 结构强度”组成。
  **置信度低于阈值的目标块不注入任何细节，直接回退保守双三次重采样**；
  注入的高频还经过能量限幅，避免错误匹配凭空制造边缘/文字。
  色度通道始终只做双三次上采样，细节迁移只发生在亮度通道。
- **观测残差检验**：重建图经同一降质模型投回输入尺度，逐像素计算残差，
  输出残差图、RMS 与峰值；亮度域与 RGB 域两轮反投影把重建约束到观测一致。
- `png.js`：自带 PNG 解码/编码（5 种过滤器、CRC、zlib），无外部图像库。

### 该方法不能保证恢复唯一原图

单个低分辨率观测对应许多合法的高分辨率图像。自相似迁移是**约束下的估计**：
观测残差小只说明重建与降质模型一致，**不代表等于真实原图**。缺乏自相似的区域
会被置信度门控判为不可信而回退，系统不会复制相似纹理去编造不存在的文字或边缘。

## 测试场景（`tests/`）

`make_test_images.js` 用固定种子生成 256px 参考图，并按引擎的同一降质模型生成
128px 输入：

| 场景 | 特征 | 实测（2×，默认参数） |
|---|---|---|
| `panes` 重复窗格 | 大量重复子结构 | 迁移 97%，PSNR 较双三次 **+3.93 dB** |
| `thinlines` 细线/类文字笔画 | 1–2px 结构，降采样丢失 | 迁移 76%，PSNR **+2.27 dB**，梯度误差下降 |
| `texture` 随机中性纹理 | 统计自相似但无精确重复 | 迁移 52%，PSNR 仅 +0.52 dB，以回退为主 |
| `unique` 缺乏自相似 | 平滑渐变+唯一物体 | 大面积回退，PSNR +1.14 dB，不编造细节 |

随机纹理场景的噪声在 RGB 三通道完全相等（中性灰，色度能量为 0），因此若 SR 输出
出现任何色度都可直接判定为伪影——实测 SR 色度能量同样为 0。

**参考清晰图（`*_HR.png`）只在 `tests/evaluate.js` 中用于 PSNR/梯度误差评价，
从不进入匹配器或候选搜索。** 引擎与服务器代码中没有任何读取 HR 的路径。

## 复现性

- 管线内不使用随机数；同输入同参数两次运行逐像素一致（已验证最大像素差为 0）。
- 每次 CLI 运行写出 `*_run.json`（全部参数、Node 版本、诊断）与 `*_matches.json`
  （每个目标块的候选索引与完整代价分解），配合源码即可复现同一结果，
  而不是只给一张对比图。
- 运行 `node tests/reproduce.js 2` 可端到端重建 `tests/outputs/scale2/` 全部产物。

## 工程结构

```
engine/        自相似内核：图像/重采样、PNG 编解码、匹配器、超分管线
cli/server.js  本地 Web 界面服务器（内核驱动控件、失败反馈）
cli/run_sr.js  单次重建 CLI（含匹配索引与运行清单）
cli/sweep.js   参数影响扫描
web/           浏览器界面（只渲染内核返回的结果，无自带图像处理）
tests/         测试图生成、评价（HR 仅在此使用）、一键复现
runs/          实际运行产物示例
```
